# Fraud-triage console

Next.js L1 fraud-triage console at `/triage`: queue, case view, face clusters, audit trail. Talks to the attest edge function (`NEXT_PUBLIC_ATTEST_API_URL`); sign in with the shared `ANALYST_TOKEN`. Start it from the repo root with `pnpm dev` so it binds to the LAN.

See the root [README](../../README.md).
